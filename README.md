# 8 位动态扫描显示电子时钟（8051 + DS1302）

基于 AT89C52 的电子时钟：DS1302 提供实时时钟，单片机通过动态扫描方式驱动 8 位显示模块，显示 `HH-MM-SS` 格式的时间，中间两位用作分隔符。

工程包含原理图和实物照片，方便对照硬件复现。

## 功能

- DS1302 读取时、分、秒
- 8 位动态扫描显示，格式为 `HH-MM-SS`
- 上电时向 DS1302 写入初始时间（写保护开关控制）
- BCD 与十进制转换

## 硬件

| 器件 | 说明 |
| --- | --- |
| AT89C52 | 主控，Keil 工程中配置为 24 MHz |
| DS1302 | 实时时钟，三线串行接口 |
| 74HC245 | 显示数据与位选缓冲 |
| ULN2803A | 位驱动（达林顿阵列） |
| 8 位显示模块 | 并行驱动，动态扫描 |

## 引脚定义

按当前源码：

| 功能 | 引脚 | 说明 |
| --- | --- | --- |
| 位选 | P0 | 逐位扫描输出 |
| 段码 | P1 | 段数据输出 |
| DS1302 SCK | P1.0 | 串行时钟 |
| DS1302 SDA | P1.1 | 数据线 |
| DS1302 RST | P1.2 | 复位/片选 |

> 源码中 DS1302 的三根信号线定义在 `P1.0`–`P1.2`，而 `P1` 同时用作段码输出。不同开发板的接线方式不一样，移植到自己的板子前请先核对这三根线的实际连接，并修改 `src/ds1302.c` 顶部的 `sbit` 定义。

## 编译

1. 用 Keil µVision（C51）打开 `keil/SEG8X8_para.uvproj`。
2. 目标器件为 AT89C52，确认已勾选生成 HEX 文件。
3. 编译后用编程器下载到单片机。

## 显示原理

`DisplayLED()` 依次选中每一位，把对应的段码写到数据口，靠人眼视觉暂留形成稳定显示。`ShowTime()` 先从 DS1302 读取时间并转换为十进制，再拆分出时、分、秒的每一位，查表得到段码码型。
